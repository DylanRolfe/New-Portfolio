snake ai

A reinforcement-learning agent that taught itself to play Snake.

role
Solo project
when
April 2025
built with
Python, PyTorch, Pygame, Matplotlib
result
Record score of 74 after 1,000 training games.

what i did

  • Built a Snake game in Pygame for the agent to play.
  • Trained a deep Q-learning agent in PyTorch with an 11-feature state and one 256-unit hidden layer.
  • Tracked score per game in Matplotlib to see when learning took off.
  • Wrote up how it works for a general audience.
