organizo

A personal assistant that lives in Telegram. Send it a voice note or a message and it schedules calendar events, summarises email and manages tasks.

role
Solo project
when
October 2025
built with
n8n, OpenAI GPT and Whisper, Telegram, Google Calendar, Gmail, Google Tasks
result
Cut AI calls per request from several to 1–2, lowering API cost.

what i did

  • Built the assistant as an n8n workflow that takes voice or text from Telegram.
  • Used Whisper to transcribe voice notes and GPT to work out what to do with them.
  • Connected Google Calendar, Gmail and Google Tasks so it can schedule events, summarise email and manage tasks.
  • Reworked the flow so each request needs 1–2 AI calls instead of several.
